The AI Moral Code project has completed a comprehensive stratified semantic analysis of 291+ global ethics documents, resulting in a refined list of 12 canonical values for AI governance. This core set is grounded in empirical frequency, sectoral breadth, and ethical salience between 2006 and 2025.

Key inclusions:  
- **Beneficence**  
- **Dignity**  
- **Fairness**  
- **Justice**  
- **Responsibility**  
- **Trust**

And critically, **Innovation** and **Sustainability** are recognized for their dual roles as ethical imperatives and operational enablers.

Explore how these values were derived and scored using the Composite Value Score (CVS) method, and learn about the Ethical Salience Tracker (EST), a forward-facing tool that keeps the value set adaptive over time.
